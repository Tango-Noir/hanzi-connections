# 汉字连线

单字分组益智小游戏：4×4 网格，每次点选 4 个字，若 4 个字同属一组则消除该组。
解出全部 4 组即胜利；最多允许错 4 次（顶部的红心扣完即止）。

## 怎么玩

浏览器打开 `index.html` 即可（直接双击就能玩，也可以部署到任意静态托管）。

- 点选 4 个字 → 提交
- 选错时若与某组只差 1 个字，会提示「差一点」
- 「洗牌」只打乱未解出的字，已解出的组不动
- 同一日期的题目洗牌结果固定（按日期做随机种子）

## 题目数据

全部题目在 `puzzles.js`（格式说明见文件末尾注释）。
按 `date` 字段取当天题目；`category` 自由填写，`color` 可选（yellow/green/blue/purple）。

## 更新题目

只需修改并重新上传 `puzzles.js`，其余文件不动。
