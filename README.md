# 汉字连线

分组益智小游戏。首页选择挑战类型，4×4 网格，每次点选 4 个字或词，若同属一组则消除该组。
解出全部 4 组即胜利；最多允许错 4 次（顶部红心扣完即止）。

## 挑战类型

- **单字**：16 个单字
- **二字**：16 个二字词
- **四字**：16 个四字词
- **教程**：固定的例题（内容、摆位永远不变），日期功能在教程中不可用

三种每日挑战的规则相同：同一日期的题目洗牌结果固定（按日期做随机种子），日期选择器中只有已出题的日期可以选，未出题的日期变灰，整月无题则翻不到那个月。

## 怎么玩

浏览器打开 `index.html` 即可（直接双击就能玩，也可以部署到任意静态托管 / GitHub Pages）。

- 点选 4 个字或词 → 提交
- 选错时若与某组只差 1 个字，会提示「差一点」
- 「洗牌」只打乱未解出的字

## 题目数据

三个独立题库，格式相同（`date` + 16 个 `items` + 4 组 `groups`，`category` 自由填写，`color` 可选）：

| 文件 | 变量 | 内容 |
|---|---|---|
| `puzzles.js` | `window.PUZZLES` | 单字 |
| `puzzles-2zi.js` | `window.PUZZLES_2ZI` | 二字 |
| `puzzles-4zi.js` | `window.PUZZLES_4ZI` | 四字 |

## 更新题目

修改对应题库文件并重新上传即可，其余文件不动。
